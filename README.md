# Linux System Audit Lab

A practical engineering laboratory for Linux system auditing,
Bash scripting, performance benchmarking, and infrastructure automation.

## Objectives

- Develop Linux system auditing scripts.
- Study Linux internals and command-line utilities.
- Benchmark alternative shell scripting techniques.
- Build a modular Linux auditing toolkit.
- Practice testing, automation, and DevOps workflows.
